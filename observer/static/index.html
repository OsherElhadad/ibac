Pipeline

What the demo is showing
  1. User asks for a refund with a partial transaction ID.
  2. Finance agent proposes a tool call and SPARC reflects before execution.
  3. SPARC blocks the hallucinated ID and the agent asks for clarification.
  4. User provides the full ID, then the refund chain completes through backend tools.
  5. User later asks to process an invoice that contains a malicious outbound instruction.
  6. IBAC intercepts the resulting POST and blocks it as prompt injection.
